# TrenchMate Privacy Policy

Last updated: 2026-09-19

TrenchMate ("the Extension") is a browser extension that enhances the
browsing experience on gmgn.ai, fomo.family, and pump.fun.

## Data Collection

The Extension does NOT collect, store, or transmit any personal data to
the developer or any third party. There is no backend server operated by
the developer.

## Local Settings

User preferences (feature toggles and numeric thresholds) are saved using
the browser's built-in `chrome.storage` API. This data stays in your own
browser (and, if you are signed in, syncs through your own Google account).
It is never sent to the developer.

## Page Access

The Extension only runs on gmgn.ai, fomo.family, and pump.fun. On these
pages it reads on-page information (such as token contract addresses) solely
to build navigation links and to request preview data from those same
sites' public interfaces. This processing happens locally in your browser.

## Third-Party Requests

To display previews and look up on-chain information, the Extension may
request data from the trading sites' own public APIs and public block
explorers. These requests are made directly from your browser to those
services and are subject to their respective privacy policies.

## Contact

For questions about this policy, open an issue at this repository.
